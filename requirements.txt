# Everything the offline half of this repository needs: the simulator, the QR
# and visual-odometry front ends, the fusion filter, the controller, the test
# suite and the analysis scripts. No ROS 2 installation is required for any of
# it, which is what lets CI run the real algorithms in seconds.
#
# Deliberately unpinned to a single version. The numbers in docs/RESULTS.md
# reproduce identically on numpy 1.26 / OpenCV 4.11 (Windows, Python 3.9) and
# on numpy 2.x / OpenCV 4.10 (Ubuntu, Python 3.11), because every stochastic
# element takes an explicit seed. Pinning would hide it if that stopped being
# true.
numpy>=1.21
scipy>=1.8
pyyaml>=5.4

# QR detection and decoding, the pinhole camera model, solvePnP and the
# Lucas-Kanade tracker all come from OpenCV. `opencv-python-headless` rather
# than `opencv-python` because nothing here opens a GUI window and the headless
# wheel does not drag in a GTK stack on a CI runner.
#
# Capped below 4.14. The weekly reproduction of the committed results is what
# found the need. On OpenCV 5.0 the reference flight (simulated) lost
# localisation more often: availability fell from 0.957 to 0.781 and the 95th
# percentile position error rose from 0.328 m to 0.653 m. On 4.14 the reference
# flight stays within tolerance but the lossy-link failsafe case is landed by
# LOCALISATION_LOST after four of five waypoints. 4.11, 4.12 and 4.13 fly that
# case as committed, 4.11 and 4.13 reproduce the reference metrics exactly and
# the scheduled CI job re-flies every case on whatever this resolves to.
# Lifting the cap means re-deriving the results and explaining what changed.
opencv-python-headless>=4.7,<4.14

# H.264. The Tello streams raw H.264 on UDP 11111 and PyAV is FFmpeg's
# libavcodec from Python: the driver decodes with it and the emulator encodes
# with its bundled libx264. The wheels ship FFmpeg, so nothing else to install.
av>=12

# Figures and the trajectory-error tables.
matplotlib>=3.5
pandas>=1.3

# Test and lint.
pytest>=7.0
# Pinned: an unpinned linter fails CI on a tree that has not changed.
ruff==0.17.1
